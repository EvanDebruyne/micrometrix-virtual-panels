Try this

  1. Open Titrate, tap Auto Titrate and Confirm. Watch the opening dose, the settling after each dose, and the doses shrinking as the reading closes on zero. Set speed to ×10 on the right to watch a whole run in a few seconds.
  2. When it ends, open Files: the run is already stored on the unit. Press Export run to copy it to the stick (or Export all for every stored run), then tap it in the file list on the right to read the CSV.
  3. Set Titrant bottle: Empty and run again. The pump turns but nothing arrives, and after eight doses (and at least a tenth of Max titrant) that together move it less than 3 mV the titrator stops with No response.
  4. During a run, set Sensor: Cable cut. The run ends, Home shows ---- and SENSOR FAULT, and Start, Auto and ZERO are dimmed until the cable is back.
  5. Tap the yellow RELATIVE chip on Home to switch to the absolute reading. The small grey line under it is the other one.
  6. On Files, press Export configuration and open PCA_Config.txt on the right: every setting as plain text. Change a setting, then Import configuration puts it back.
  7. Tap Mode beside Auto Titrate to choose Cautious, Normal or Aggressive, then run the same sample again (tap the sample button for a fresh one): fewer, bigger doses and shorter waits, or more, smaller ones.
  8. Set Pump motor supply: Off and press 1 Drop on the Pump page: the steps count but nothing reaches the sample. Turn on Config → Pump → Power sense and the page says NO POWER and refuses instead.
  9. Press Make calibration due. Tap the flashing CAL DUE badge, unlock with PIN 1234, then Mark calibrated. The same PIN guards Config → Sensor → Input @ 4 mA.

What is real here

Screens, layout, colours, wording, menus, the keypad, the auto-titrator's control logic and its messages, the sensor-fault rule, the run file format (Schema 4), the results log, the Signal Health formula and the service PIN rules follow the firmware source. The sample chemistry, the pump and the sensor are simulated, and the runs and health history before you opened the page are generated so the screens are not empty. A fresh sample is placed in the cell whenever a new run starts after a finished one. Fonts are close, not identical.
